VIENSCO SOLAR – flat version (every file in one folder, no sub-folders)

PUT IT ONLINE (free, one time)
1. GitHub > New repository (Public) > "uploading an existing file" > upload ALL files in this folder > Commit.
2. Settings > Pages > Branch: main, folder: / (root) > Save. After 1-2 minutes you get
   https://YOURNAME.github.io/REPO-NAME/

INSTALL (open that https link, wait a few seconds so files are saved)
- Android (Chrome): tap "Install" on the bar at the top, or menu (3 dots) > Install app.
- iPhone / iPad: open in Safari > Share > Add to Home Screen.
- Windows / Mac / Chromebook (Chrome or Edge): click the install icon at the right end of the address bar,
  or menu > Install Viensco Solar. (Mac Safari: File > Add to Dock.)
- Check progress any time: app > More > Install check (all ticks = ready).

AFTER YOU CHANGE ANY FILE
Edit "CACHE" at the top of sw.js (viensco-solar-v4 -> v5). Phones and PCs then pick up the update.
